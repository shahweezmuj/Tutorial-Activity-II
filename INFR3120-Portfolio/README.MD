# Personal Portfolio Website

## Overview

This website is my personal portfolio. It introduces me, presents my
skills and education, showcases my projects, and provides contact information.

## Website Pages

- index.html: Home page and introduction
- about.html: Background, skills, experience, education, and introduction video
- projects.html: Projects and technical work
- contact.html: Contact information and validated contact form

## Technologies Used

- HTML5
- CSS3
- Git and GitHub
- GitHub Pages

## Project Structure

- index.html: Home page
- about.html: About page
- projects.html: Projects page
- contact.html: Contact page
- css/style.css: Main website styling
- css/laptop.css: Laptop and desktop media query
- css/tablet.css: Tablet media query
- css/mobile.css: Mobile media query
- images/: Images used by the website
- videos/: Introduction video

## Responsive Design

Mobile:
600px and below. Content changes to one column and navigation
is rearranged to fit smaller screens.

Tablet:
601px to 900px. Content widths, spacing, and card layouts
are adjusted for medium-sized screens.

Laptop and desktop:
901px and above. The website uses wider content areas and
multiple-column layouts where appropriate.

## Gradients

The navigation header uses a 135-degree linear gradient
to create a subtle background transition.

The page heading underline uses a 90-degree linear gradient
from orange to a lighter orange.
